🎬 How to add to OBS / Streamlabs

  1. Click + in your Sources panel and choose Browser Source.

  2. Paste your generated widget URL into the URL field.

  3. Set width to 90 and height to 280. Tick Shutdown source when not visible.

  4. Make sure Custom CSS is blank, then click OK and position the widget wherever you like on your scene.

  5. Start streaming — the bar rises automatically as your chat heats up! 🔥

🧠 How the score is calculated

No AI API calls, no backend — all analysis runs directly in your browser using a weighted heuristics engine. Zero latency, zero cost.

💬 Message Volume Messages per 20-second rolling window. The more the chat talks, the higher the base score. Weight: 55%
🔤 CAPS Ratio Proportion of ALL-CAPS words. High caps = hype energy. Hype signal: 30%
😂 Hype Emotes Known Twitch emotes (Pog, OMEGALUL, KEKW, Clap…) detected per message. Hype signal: 30%
🔑 Hype Keywords Trigger words like "clip it", "insane", "gg", "lets go", "sheesh"… Hype signal: 25%
❗ Exclamation Marks Raw count of ! per message. "LETS GO!!!" hits harder than "nice". Hype signal: 15%

✨ When chat goes quiet the bar smoothly decays, keeping the visualization honest.
